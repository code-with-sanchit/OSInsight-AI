# Changelog

All notable changes to the OSInsight-AI Advanced Disk Scheduling Simulator are documented here.

## 2.0.0 (2026-11-09)

- Advanced Disk Scheduling Simulator core suite with 6 classic algorithms: FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK.
- Explainable AI multi-objective policy selector supporting Performance, Fairness, and Balanced target profiles.
- Interactive CustomTkinter desktop dashboard with real-time head path visualization.
- Automated PDF report exporter using ReportLab for academic lab evaluations.
- Comprehensive unit test suite covering algorithm correctness, head path sequencing, and policy ranking.
